# Grimoire Inbox (public client)

Static, publicly-hostable idea/card inbox for Grimoire. Talks ONLY to the GitHub Contents API of
your PRIVATE `grimoire-exchange` repo, using a fine-grained token you paste in (stored in your
browser's localStorage, never here). No secrets are baked into this page.

Deployed from `grimoire-kb/web/inbox.html`. See `grimoire-kb/docs/EXCHANGE-SETUP.md`.
